CLND

Command-Line Native Distributor — a package manager for Windows

🪟 Windows 10 / 11 · 64-bit
Download clnd.exe Install with one line

Install

Open PowerShell and paste this one line — it downloads CLND and adds it to your PATH:

irm https://markabrazuk336-maker.github.io/clnd/install.ps1 | iex

Then open a new terminal and run clnd update.

Use it

:: get the catalog (1600+ programs)
clnd update
:: search and install
clnd search ripgrep
clnd install ripgrep
:: keep everything current
clnd upgrade --all
:: update clnd itself
clnd up

What it does

🔎 One catalog

Search and install from the same package catalog as Scoop — thousands of tools.

⚡ Portable installs

Apps go in your user folder, with shims on PATH. No admin, no clutter.

⬆️ Self-updating

clnd up updates the tool itself from this page — like brew upgrade.

🔒 Sealed updates

Updates ship as encrypted .tju files that are rejected if tampered with.
